About the logo: until you add a logo web address, the logo is built into the signature. Outlook and Apple Mail keep it when you paste. Gmail usually drops it, so in Gmail use the image button in the signature editor to insert the logo file instead.

Gmail

  1. Click Copy signature.
  2. Gmail → Settings (gear) → See all settings → General → Signature → Create new.
  3. Paste, then Save Changes at the bottom of the page.
  4. If the logo is missing, place the cursor above your name and use the image button to insert the logo file.

Outlook

  1. Click Copy signature.
  2. Outlook → Settings → Mail → Compose and reply (new Outlook), or File → Options → Mail → Signatures (classic).
  3. Create a new signature, paste, and save.
  4. Set it as the default for new messages; use the short one for replies.

Apple Mail

  1. Click Copy signature.
  2. Mail → Settings → Signatures → +.
  3. Untick “Always match my default message font”, then paste into the right-hand box.
